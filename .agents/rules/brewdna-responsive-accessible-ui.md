Twórz UI mobile-first, responsywne i dostępne.

- Projektuj dla małych i dużych telefonów oraz tabletów; nie zakładaj jednej
  stałej szerokości ekranu.
- Uwzględniaj SafeArea, klawiaturę, notch, dynamiczną wielkość tekstu, długie
  tłumaczenia PL/EN oraz orientację ekranu.
- Nie obcinaj tekstu ani nie używaj sztywnych wysokości, jeśli treść może
  rosnąć.
- Zapewnij minimalne wygodne pola dotyku, semantyczne etykiety oraz wyraźny
  focus.
- Dbaj o kontrast tekstu i elementów interaktywnych, zwłaszcza na
  półprzezroczystych warstwach.
- Każdy ekran z danymi zdalnymi ma mieć dopracowane stany: loading, empty, error
  i retry.
- Animacje są krótkie, celowe i nie blokują interakcji. Respektuj reduced
  motion, jeśli jest dostępne.
