BrewDNA ma wyglądać jak dopracowany, premium produkt dla miłośników piwa — nie
jak generycznie wygenerowany interfejs.

Kierunek: głęboka ciemna paleta, ciepłe akcenty piwne, wyrazista typografia,
subtelne szkło/liquid glass, duże oddechy, eleganckie animacje i silna
hierarchia informacji.

Priorytety:

1. Szybkość i niezawodność ponad efekty wizualne.
2. Czytelność oraz dostępność ponad dekorację.
3. Jeden spójny design system ponad indywidualne style ekranów.
4. Zachowanie logiki backendowej i kontraktów API podczas zmian frontendu.
5. Każdy ekran ma wyglądać kompletnie w stanach: dane, ładowanie, pusto, błąd.
